# Islandly 0.5.0 — حالة التنفيذ والتحقق

تاريخ المراجعة: 2026-10-28. الأساس: `3cfd4909143d6a87d5d6a61cbe94592a6824a263`، إصدار 0.4.0. هذه توسعة لمعمارية Electron الحالية وليست إعادة كتابة. لا توجد قياسات أداء على Windows حتى الآن، ولا ينبغي اعتبار هذه النسخة إصدارًا إنتاجيًا قبل اجتياز قائمة القبول أدناه.

## معنى الحالة

- **موجود/مضاف:** يوجد مسار برمجي وواجهة فعلية؛ لا تعني الكلمة أن التكامل الأصلي اختُبر على جهاز Windows.
- **مشروط:** يحتاج إعدادًا أو إذنًا أو جهازًا أو برنامجًا خارجيًا.
- **جزئي:** الجزء المنفذ محدد بوضوح؛ الجزء الآخر ليس ميزة مكتملة.
- **غير منفذ:** لا نعرض زرًا يوهم بوجوده.

## التحقق المنفذ بالفعل

- `npm test`: اختبارات ICS، مساعدات updater، 72 assertion للوحة الأوامر، AI mock، 7 اختبارات انحدار R1/R2/R3/R5/R6/R7/R8، واختبار رفض رسائل عامل وسائط قديم وأوامر مؤجلة بعد الإيقاف، تكامل الخدمات وDOM للواجهة.
- التكامل يشغّل sharp وpdf-lib فعليًا في worker: WebP وتغيير الحجم ودمج PDF، ويتحقق من بقاء الأصول. يختبر تصنيف وخصوصية وحدود الحافظة، LRC وتجميع الإشعارات والبحث والإعدادات.
- اختبار DOM يشغّل سكربتات HTML الحقيقية مع IPC mock وbridge مجمّد. يتأكد من الوصول إلى 20 عنصر حافظة و15 مهمة والمذكرة والكلمات واللوحات والمؤقت. ليس اختبار layout أو GPU أو SMTC.
- `npx electron test/update-flow.js --no-sandbox --headless --disable-gpu --ozone-platform=headless`: نجح على Linux؛ رفض ملف معدل، staging، رفض base أحدث، وإقلاع النسخة المرحلية. `--no-sandbox` لا يدخل إعداد إنتاج Windows.
- `npm audit --omit=dev`: أظهر sharp القديم تنبيهات libvips/libheif/librsvg؛ جرى تحديثه إلى 0.35.5 وإعادة اختبار التحويلات. نتيجة الفحص التالية: صفر ثغرات إنتاجية معروفة بتاريخ المراجعة، وليست ضمانًا ضد ثغرات غير مكتشفة.
- فحص syntax لكل JavaScript وفحص diff. تفاصيل حالة CI على Windows Server موجودة في PR وActions؛ لا تحل بيئة CI محل اختبار لابتوب Windows 10/11 والأجهزة الحقيقية.
- نجح OCR الحقيقي محليًا على صورة مولّدة تحمل `ISLANDLY 12345` بمحرك ara+eng وتنزيل بيانات اللغة. يغطي `npm run test:ocr` ذلك؛ لا يثبت جودة التعرف على نصوص عربية واقعية.
- نجحت اختبارات Windows Server 2025 في GitHub Actions (npm test وOCR وElectron update-flow وsmoke)، بما فيها رفض IPC من نافذة غريبة وتهيئة Win32 FFI. لم تُنفّذ اختبارات جهاز Windows تفاعلي أو قياسات CPU/RAM/battery أو دقة OCR العربية أو خدمات حقيقية مدفوعة. حاولنا GUI داخل بيئة العمل لكن لا يوجد X display/GTK قابل للتشغيل؛ DOM لا يعوض ذلك.

## الأمان والخصوصية

الإعدادات والمذكرات محفوظة محليًا بحفظ ذري. مفاتيح API عبر safeStorage/DPAPI ولا تعود للـrenderer. رابط ICS الخاص محفوظ في settings.json كنص حساس؛ لا تشاركه أو تشارك هذا الملف. البيانات المحلية ليست خزنة مشفرة شاملة. الحافظة والإشعارات الجديدة في الذاكرة فقط. بيانات الوقت على القرص محليًا ويمكن إيقاف جمعها.

الشبكة: GitHub للتحديث/الإشعارات/CI، Open-Meteo للطقس، open.er-api للعملات، رابط ICS الذي تحدده، LRCLIB عند تفعيل الكلمات، Anthropic عند إرسال نص صريح، وبيانات لغة Tesseract في أول OCR. أدوات خارجية مثل rembg قد تحمل نماذجها. لا telemetry مضافة. مشاركة LAN غير مشفرة ولا تبدأ تلقائيًا.

التحديثات تفحص hash Git لكل ملف وصلاحية المسار والحجم، لكنها تثق بحساب ومستودع GitHub؛ hash ليس توقيع ناشر مستقلًا. حماية الحساب والمراجعة قبل الدمج أساسية. هذه النسخة ترفع base إلى 3، ولذلك تحتاج الحزمة الكاملة من 0.4.0؛ تنزيل JS وحده لن يثبت sharp/Tesseract/pdf-lib أو bootstrap الجديد. MSIX هنا غير موقع ولا يُثبّت أو يُوثق له أي شهادة تلقائيًا.

لا ننسخ كود مشاريع Dynamic Island أخرى. التبعيات: Electron MIT، adhan MIT، koffi MIT، SMTC monitor MIT، Anthropic SDK MIT، pdf-lib MIT، sharp Apache-2.0، Tesseract.js Apache-2.0؛ حزمة libvips الثنائية لها إشعارات LGPL وتراخيص codecs التابعة. حافظ على LICENSE/NOTICE للتبعيات وراجع ملفات الطرف الثالث عند التوزيع. FFmpeg وrembg والنماذج غير مضمّنة؛ الترخيص يتحدد بالبناء/النموذج الذي يثبته المستخدم. لا يُعتبر ذلك إجازة لإعادة توزيع أي binary مجهول.

## قائمة قبول Windows قبل الدمج والإصدار

1. Windows 10 build 19041+ وWindows 11 x64: تثبيت نظيف، تشغيل ثانٍ، tray، بدء التشغيل، إغلاق نظيف؛ لا صلاحيات Administrator.
2. Spotify وEdge/YouTube وVLC: غلاف متأخر، تبديل مصدر، seek غير مدعوم، تغيير مسار سريع، خروج المصدر، استيقاظ، تشغيل 8 ساعات.
3. شاشتان 100%/150%/200%، شاشة يسار بإحداثيات سالبة، تغيير primary وDPI، نزع الشاشة المختارة، شريط مهام auto-hide؛ النقر خارج الحواف لا يعترض التطبيق.
4. لعبة exclusive/borderless وفيديو، لعبة على الشاشة الأخرى، Alt+Tab وUAC وremote desktop؛ الجزيرة لا تحاول الظهور فوق secure desktop.
5. لغة RTL/LTR أثناء مؤقت فعال، لوحة كتابة ومذكرة ومساعد ومفاتيح اختصار متعارضة؛ التحقق من layout فعليًا.
6. الحافظة: نص وصورة وpassword-manager markers، تعطيل ثم تفعيل، lock/unlock، paste في تطبيق عادي/مرتفع (قد تمنع UIPI ذلك)، وتحقق يدوي من عدم تسجيل الأسرار.
7. MSIX: بناء الجسر وmakeappx، توقيع بشهادة ناشر معتمدة **بقرار توزيع منفصل**، تثبيت/رفض/منح/سحب إذن الإشعارات، إزالة الحزمة؛ لا توقع نجاح ZIP وحده.
8. OCR عربي مختلط ودقة/شاشات مختلفة، إلغاء وحجم كبير/ملف تالف، تسجيل/توقف/سكون وحد 60 ثانية؛ تحقق من تنقية ملفات OCR المؤقتة.
9. PDF محمي/كبير وصور EXIF/WebP، أدوات خارجية مفقودة، فشل FFmpeg/rembg، عدم الكتابة فوق الأصل؛ LAN link/expiry/stop والجدار الناري.
10. ICS/timezone/DST وfeed تالف، موقع/طريقة صلاة، مفاتيح AI/GitHub غير صالحة وانقطاع الشبكة وrate limits؛ منع النتائج القديمة بعد إيقاف الميزة.
11. قياس idle/expanded/animation/recording بمقاييس فعلية (CPU، RSS/private bytes، handles، wakeups) ومقارنة 0.4.0، ثم soak 8–24 ساعة وسكون/استيقاظ.
12. update A→B→C، code-path dependency lookup، ملف تالف، rollback، انقطاع التحميل، تشغيل نسختين؛ نسخة base2 ترفض hot-update إلى base3. العودة: إغلاق التطبيق ثم تشغيل الحزمة السابقة؛ احتفظ بنسخة بيانات قبل اختبار الترحيل.

## مراجع التنفيذ (اطلاع 2026-10-28)

- [Electron contextBridge](https://www.electronjs.org/docs/latest/api/context-bridge) — الكائنات العابرة للـbridge تُنسخ وتجمد.
- [Electron Clipboard](https://www.electronjs.org/docs/latest/api/clipboard) — استخدام API غير متزامن وصور ClipboardItem في Electron 45.
- [Electron screen](https://www.electronjs.org/docs/latest/api/screen) و[BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window) و[session capture](https://www.electronjs.org/docs/latest/api/session#sessetdisplaymediarequesthandlerhandler-opts).
- [Microsoft UserNotificationListener](https://learn.microsoft.com/en-us/windows/apps/develop/notifications/app-notifications/notification-listener) — capability وإذن من UI thread وسحب الإذن.
- [WindowsAppSDK issue 6172](https://github.com/microsoft/WindowsAppSDK/issues/6172) — فشل NotificationChanged في unpackaged WinUI؛ سبب عدم ادعاء العمل على ZIP.
- [WindowsAppSDK 2.4.0](https://www.nuget.org/packages/Microsoft.WindowsAppSDK/2.4.0) — إصدار مثبت للجسر، وليس اختيار experimental.
- [GetSystemPowerStatus](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-getsystempowerstatus) و[SYSTEM_POWER_STATUS](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-system_power_status) — قيم unknown/no battery.
- [GSMTC](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportscontrolsessionsmanager) — تعتمد البيانات على تطبيق المصدر.
- [UIPI وSendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput) — لا ضمان للصق في تطبيق أعلى صلاحية.
- [Tesseract.js](https://github.com/naptha/tesseract.js)، [sharp](https://sharp.pixelplumbing.com/)، [pdf-lib](https://pdf-lib.js.org/)، [LRCLIB API](https://lrclib.net/docs) — التنفيذ والتراخيص والقيود.

هذه ليست مراجعة لكل مشاريع الإنترنت؛ نطاق العمل هنا مستودع Islandly ومراجعه الرسمية والتبعيات المرتبطة بالإصلاحات. الفرضيات المتعلقة بالأجهزة والألعاب والمقاييس ليست نتائج اختبارات مثبتة.

- [sharp security advisory GHSA-wq5f-xc86-pv6w](https://github.com/lovell/sharp/security/advisories/GHSA-wq5f-xc86-pv6w) — سبب تحديث حزمة معالجة الصور إلى 0.35.5.

بناء جسر WinUI 3 نجح في CI على Windows Server 2025؛ السماح/رفض الإذن وتدفق إشعارات مستخدم حقيقي داخل MSIX ما زالا يحتاجان اختبارًا تفاعليًا.
