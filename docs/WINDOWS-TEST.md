# قائمة اختبار ويندوز (ينفذها وليد على جهازه)

هذي الأشياء ما نقدر نختبرها في بيئة Linux أو في CI بدون شاشة. نفّذ كل بند، وحط ✅ أو ❌ واكتب ملاحظة قصيرة. لو ❌ صوّر الشاشة وأرسل ملف السجل: كليك يمين على أيقونة الجزيرة ← "فتح مجلد السجلات والبيانات" ← `islandly.log`.

اكتب فوق: رقم الإصدار (من الإعدادات)، نسخة ويندوز (10 أو 11)، ونوع الجهاز.

## ٧. شاشتين بدقة (DPI) مختلفة

اربط شاشة خارجية، وخلّ "Scale" مختلف بين الشاشتين (مثلاً اللابتوب 150% والخارجية 100%) من إعدادات العرض حق ويندوز.

| # | الخطوة | النتيجة المتوقعة | ✅/❌ |
|---|---|---|---|
| 7.1 | شغّل Islandly | الجزيرة في أعلى منتصف الشاشة الرئيسية، حجمها طبيعي ومو مقصوصة | |
| 7.2 | غيّر الشاشة الرئيسية من إعدادات ويندوز | الجزيرة تنتقل للشاشة الرئيسية الجديدة | |
| 7.3 | افتح أكبر لوحة (مثلاً الموسيقى) على كل شاشة | النص واضح ومو ضبابي، والأزرار تنضغط في مكانها الصحيح | |
| 7.4 | افصل الشاشة الخارجية والتطبيق شغال | الجزيرة ترجع للابتوب وما تختفي | |
