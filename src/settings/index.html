الصحة والإنتاجية

مساحات العمل ولوحة الأوامر

افتح لوحة الأوامر بـ Ctrl + Alt + Space. كل سطر مساحة عمل: الاسم ثم نقطتان ثم العناصر مفصولة بـ |

المفاتيح (تُشفَّر على جهازك)

قراءة PR وCI للمستودعات الخاصة تحتاج صلاحيات الرمز المناسبة. لا يغيّر التطبيق صلاحيات حسابك.

أنشئ رمزاً من GitHub ← Settings ← Developer settings ← Personal access tokens (classic) بصلاحية notifications فقط.

التقويم والاجتماعات

من Google Calendar: الإعدادات ← اختر التقويم ← «العنوان السري بتنسيق iCal». الرابط سري، لا تشاركه مع أحد. يُحفظ على جهازك فقط.

التحديثات

التطبيق

يغلق الجزيرة تماماً. للتشغيل مرة ثانية افتح Islandly.exe.

الوسائط والشاشات

Alt + سكرول للتبديل بين الشاشات. Ctrl + سكرول في لوحة الموسيقى لتغيير الصوت.

المفضلات السريعة

كل سطر: الاسم ثم نقطتان ثم الموقع أو مسار الملف أو اسم التطبيق.

التركيز والتنبيهات

التركيز يكتم تنبيهات Islandly. للتحكم في عدم الإزعاج على مستوى Windows افتح إعداداته من لوحة النظام.

وحدات الواجهة والإضافات

يمكن إخفاء كل لوحة مستقلة. خدمات الخلفية ذات الصلة تُضبط من خياراتها أعلاه.
